Codex Usage Monitor 安装说明
============================

系统要求
• macOS 14 或更高版本
• 支持 Apple Silicon 与 Intel Mac

安装
1. 将“Codex Usage Monitor”拖到旁边的 Applications 文件夹。
2. 前往“应用程序”，右键点按 Codex Usage Monitor，选择“打开”。
3. 如果系统仍提示无法验证开发者，请先尝试启动一次，然后打开“系统设置 → 隐私与安全性”，在安全性区域选择“仍要打开”。该按钮通常只在尝试启动后的一段时间内显示。

首次使用
• 点击菜单栏中的 Codex 状态项。
• 优先选择“复用本机 Codex”，阅读说明后决定是否授权。
• 本机来源不可用时，选择“浏览器查看 → 应用内登录”。
• 登录会话及用量历史只保存在当前 Mac。

说明
• 这是独立开发的非官方工具，不是 OpenAI 官方产品。
• 未经 Apple Developer ID 签名和公证的测试包，首次启动可能需要手动确认。
• 不需要关闭 Gatekeeper，也不要使用命令全局禁用 macOS 安全检查。
